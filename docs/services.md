# 服務

我們專注於將 AI 與工程落地到產線與營運：

## 1) AI 客服 / 對話系統
- 專屬領域知識庫、RAG 強化、工單/CRM 串接
- 例：線上訂單、售後問答、知識查詢

## 2) 後端整合與 API
- 金流、物流、帳務、SSO 與身分整合
- 高可用/可觀測、雲端環境佈署

## 3) 視訊系統 / WebRTC
- 遠距醫療、教學/會議、錄影與法遵稽核
- 與既有系統 (EMR/掛號/客服) 無縫串接

## 4) 資安與合規
- ISO 27001/27017/27018 文件工程與自動化工具
- 雲端資安基線、存取控管、稽核輔助
