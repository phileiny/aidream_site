三強技術雷達圖

關鍵里程碑時間線

🔬 技術領先者: Google DeepMind

  • • Genie 3 實現首個實時互動 World Model
  • • 720p/24fps 視覺記憶可達1分鐘
  • • 物理一致性為「湧現」能力
  • • 與 SIMA Agent 整合驗證 AGI 路徑

💼 商業化領先者: NVIDIA

  • • Cosmos 開源策略快速建立生態
  • • Figure AI、1X 等機器人公司採用
  • • 與 Omniverse 深度整合
  • • 「讓每個開發者都能觸及通用機器人」

🚀 最快成長者: World Labs

  • • 2024年9月成立，2025年11月商業化
  • • 首個提供持久化可下載 3D 環境
  • • 李飛飛「空間智能」願景驅動
  • • 已支援 Vision Pro / Quest 3 VR

🧠 另闢蹊徑者: Meta (JEPA)

  • • LeCun 堅持非生成式路線
  • • V-JEPA 2 比 Cosmos 快 30x
  • • 抽象表徵預測而非像素生成
  • • LeCun 離開 Meta 創業專注 AMI

⚔️ Genie 3 vs Marble 核心對比

維度 Genie 3 (DeepMind) Marble (World Labs)
生成方式 實時逐幀生成 持久化生成後編輯
互動性 即時可控（鍵鼠） 創建後進行編輯
輸出格式 實時視頻流 3D 資產（可導出）
物理理解 湧現式物理一致性 尚未明確建模動態
主要應用 AI Agent 訓練 創意製作、VR/AR
開放程度 研究預覽 已商業化

🛤️ 兩大技術路線之爭

生成式路線

DeepMind, OpenAI, NVIDIA, World Labs

  • • 直接生成像素/視頻
  • • 物理理解從規模中「湧現」
  • • 商業化進展快
  • • 計算成本較高

表徵預測路線 (JEPA)

Meta (Yann LeCun)

  • • 在抽象空間中預測狀態
  • • 學習本質結構而非表面
  • • 效率高（30x faster）
  • • 仍在研究階段
