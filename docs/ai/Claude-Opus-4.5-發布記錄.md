# Claude Opus 4.5 正式發布 🚀

## 📅 發布資訊

**發布日期**: 2025年11月24日

Anthropic 正式發布了 Claude 4.5 系列的旗艦模型 - **Claude Opus 4.5**，這是目前「世界上最好的編碼、代理和電腦使用模型」，標誌著 AI 技術在專業軟體工程和複雜問題解決領域的重大突破。

## 💰 價格比較：Opus 4.5 vs Sonnet 4.5

### 價格表

| 模型 | 輸入價格 | 輸出價格 | 相對成本 |
|------|---------|---------|---------|
| **Claude Opus 4.5** | $5 / 百萬 tokens | $25 / 百萬 tokens | 高階旗艦 |

### 💡 定價亮點

- **相比前代大幅降價**: Opus 4.5 的價格比 Opus 4.1 ($15/$75) 便宜了 **66.7%**，使得旗艦級智能更加親民
- **價格策略**: Opus 4.5 定價為 Sonnet 4.5 的 1.67 倍，但提供最高級的智能和推理能力
- **最佳性價比**: 以更低的價格提供前沿的 AI 能力，特別適合需要最高智能水準的專業應用

## 🎯 Claude Opus 4.5 核心特性

### 1. 最大智能等級
- 結合最大能力與實用性能
- 在推理、編碼和複雜問題解決方面有階躍式改進
- 適合複雜專業任務、軟體工程和高級代理應用

### 2. 努力參數 (Effort Parameter)
**Opus 4.5 是唯一支援努力參數的模型**，讓你可以控制 Claude 在回應時使用的 token 數量：

- **高努力**: 最大詳盡程度,用於複雜分析
- **中等努力**: 平衡方法,適合大多數生產用例  
- **低努力**: 最具 token 效率,用於高容量自動化

### 3. 增強的電腦使用功能
- 新增「縮放」功能,可以全解析度檢查特定螢幕區域
- 適合檢查小型 UI 元素、細則文字、複雜界面

### 4. 思考塊保留
- 自動保留整個對話中的所有先前思考塊
- 在長期運行的任務中保持推理連續性
- 有效利用完整的推理歷史

## 🖥️ 在 Claude Code 中使用 Opus 4.5

### 切換到 Opus 4.5 的方法

#### 方法一: 在對話中切換
```bash
/model claude-opus-4-5-20251101
```

或使用簡短別名:
```bash
/model opus
```

#### 方法二: 啟動時指定
```bash
claude --model claude-opus-4-5-20251101
```

#### 方法三: 使用環境變數
```bash
export ANTHROPIC_MODEL=claude-opus-4-5-20251101
claude
```

### 驗證當前模型

使用 `/status` 指令查看當前使用的模型:
```bash
/status
```
